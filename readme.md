\# MentorHub



A simple, responsive mentors directory website built with vanilla \*\*HTML\*\*, \*\*CSS\*\*, and \*\*JavaScript\*\*.



\## Features

\* \*\*Mentor Cards:\*\* Displays mentor profiles, roles, and short bios.

\* \*\*Category Filter:\*\* Filter mentors by Tech, Design, or Career.

\* \*\*Session Booking:\*\* Interactive modal popup to request a 1-on-1 intro call.



\## Files

\* `index.html` — Page structure and booking modal

\* `style.css` — Responsive grid and UI styling

\* `script.js` — Filter logic and booking confirmation



\## Run Locally

Double-click \*\*`index.html`\*\* to open the website in your browser.
